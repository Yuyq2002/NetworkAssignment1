Create a network game using winsock with features like, server finding, interpolating positions, etc. The game must have a win/lose condition and should be playable by two people on different devices on the same network. 


 To start playing locally, run both the client and server projects by configuring startup projects on the solution, and selecting both of them, then running.

 To play the game press C to connect to the server. Use WASD to move around. Hold Spacebar to boost. Hold Z to see connection information. Press X to disconnect.At least 2 player need to join the game to start

The game we made has the goal of killing all your enemies. Be the last one standing to win!
